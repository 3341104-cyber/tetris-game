# Tetris Game

A simple browser-based Tetris game built with HTML, CSS, and JavaScript.

## Run locally

From the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deploy to Render

1. Push this repository to GitHub.
2. In Render, choose `New` -> `Static Site`.
3. Connect the repository.
4. Set the root directory to the repo root or the folder containing the site files.
5. Leave the build command empty.
6. Set the publish directory to `.`.
7. Deploy.

This project does not need a backend, so a static site is enough.
